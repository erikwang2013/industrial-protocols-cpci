# CompactPCI 协议包 — 机架式 PCI 总线，需 CPCI 接口桥接

> [English](README.en.md)

CompactPCI (cPCI) 机架式 PCI 总线协议。工控/电信机架标准（PICMG 2.0），需要 CPCI 接口，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-cpci
```

## 功能

CompactPCI 总线桥接、BridgeConnector 连接管理

## 所需硬件

CompactPCI 接口（标准 CPCI 机箱背板）

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Plain PHP

## 系统要求

- PHP >= 8.1
- CompactPCI 接口
- erikwang2013/industrial-protocols-kernel
